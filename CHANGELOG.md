# Changelog

All notable changes to the default organization and user health files for [@Bosaj](https://github.com/Bosaj) will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-18

### Added
- Standardized open-source community health policies (`CONTRIBUTING.md`, `CONTRIBUTORS.md`, `SECURITY.md`, `LICENSE`).
- Default GitHub Actions workflow for repository health auditing and automated link validation.
- Centralized `FUNDING.yml` configuration across all public repositories.
