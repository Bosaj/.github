# Security Policy

## Supported Versions

Security updates and critical vulnerability patches are actively delivered across all current releases in the [@Bosaj](https://github.com/Bosaj) ecosystem.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| 0.x.x   | :white_check_mark: |

## Reporting a Vulnerability

We prioritize the security and integrity of our codebase and community. If you discover a potential vulnerability, please report it responsibly:

1. **Email:** Contact `oussamaelhadji2@gmail.com` with the subject line `[SECURITY REPORT] <Repository Name>`.
2. **Details:** Include a detailed description of the vulnerability, affected components, reproduction steps, and potential attack vectors.
3. **Response SLA:** We will acknowledge receipt within 24 hours and provide an remediation timeline within 72 hours.
4. **Coordinated Disclosure:** Please allow sufficient time for remediation prior to public disclosure.
