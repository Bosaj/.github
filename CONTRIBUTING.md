# Contributing to Bosaj Ecosystem

Thank you for your interest in contributing to the **@Bosaj** open-source ecosystem!

## Code of Conduct

We are committed to providing a welcoming and inspiring community for all. Please review and adhere to our Code of Conduct in all interactions across issues, discussions, and pull requests.

## How to Contribute

1. **Reporting Issues:** Search existing issues first. Provide clear reproduction steps, environment details, and expected vs. actual outcomes.
2. **Submitting Pull Requests:**
   - Fork the repository and create your branch from `main`.
   - Ensure clean Conventional Commit messages (`feat:`, `fix:`, `docs:`, `test:`, `refactor:`).
   - Verify that all unit and integration tests pass before submitting.
   - Link any related issues in the PR description.
3. **Coding Standards:**
   - Adhere to the established styling, linting, and formatting rules of the repository.
   - Maintain comprehensive docstrings and documentation for all public APIs.
